# Version 0.3.0 — Windows checklist

Date: November 8, 2026.

- **Approval:** Approved by the maintainer on 2026-11-08 as the way to
  validate automation on Windows (Q-24 of the
  [specification](../automation-engine-specification.md#12-decisions-required-from-the-maintainer)):
  a checklist the maintainer runs and whose results are recorded from the
  report. Lines W-29 to W-52 (milestones A8 to A15) were added on
  2026-11-09 at the maintainer's request.
- **Implementation:** Run on 2026-11-09 on the maintainer's Windows machine
  by an agent, at the maintainer's request (results below and in
  [After the run](#after-the-run)). The maintainer dropped the theme lines
  (W-24, W-52) on 2026-11-09. The findings are numbered in
  [Findings](#findings); the fixes made after the run were not checked
  visually again.

Milestones A3 (external programs), A4 (`jjp/1`) and A6 (the interface) of
[0.3.0](0.3.0.md) are validated on Linux in the repository's gate. Windows
differs where the code relies on a Job Object, a console, `PATHEXT`, the
operating system's file lock and the native window, so each of those has a
line here. A behaviour that is not marked **Passed** is not claimed for
Windows.

## How to run it

1. Build and start from a clean checkout of `release/0.3.0`, on a Windows 10
   or 11 machine. Use an isolated data folder, `JYKRE_CONFIG_DIR` set to an
   empty folder, and only the local fixtures or SQLite files made for the
   check.
2. Follow each line's steps in order. Write **Passed**, **Failed** (with what
   happened) or **Not run** (with why) in the result column. Do not edit the
   steps; add a note when you had to improvise.
3. Programs used below are harmless on purpose: `ping -n 300 127.0.0.1` for a
   process that runs long, `cmd.exe /c` is **not** used (Studio refuses
   `.bat` and `.cmd`). A grandchild is a program that starts another, such as
   `powershell.exe -NoProfile -Command "Start-Process ping -ArgumentList '-n','300','127.0.0.1'; Start-Sleep 300"`.
4. Record the commit tested, the Windows version and the date at the top of
   the results.

Tested commit: release builds of `e54f667` (W-29 to W-51) and `55a6fd6`
(W-03 to W-28; W-27 on `55a6fd6` with the fix of finding 14, uncommitted)
Windows version: Windows 11 Pro 10.0.26300, 100% scaling, two 1920×1080
screens Date: 2026-11-09 By: an agent (Claude), for the maintainer

How it was run: the release build was copied out of `target/` and started
with `JYKRE_CONFIG_DIR` on an empty folder of the agent's scratch area,
`JYKRE_LOCALE=en`, synthetic SQLite files and the dev fixtures
(PostgreSQL on 127.0.0.1:55432, MySQL on 127.0.0.1:55306, profiles without a
remembered password, the fixture password typed into the prompt). The
window was driven only through its own messages: `PostMessage` for the mouse
and keys, `PrintWindow` for captures, `WM_ACTIVATE` posted to that window
so GPUI's focus events fire, and modifiers (`Ctrl`, `Shift`, `Alt`) set
with `SetKeyboardState` on the window's attached input queue, never
`SendInput`. Process trees, command lines and timings came from
`Get-CimInstance Win32_Process`. Captures are in the agent's scratch folder,
not in the repository. Improvisations are noted in the lines.
